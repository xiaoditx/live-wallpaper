# 动态壁纸管理器 - live wallpaper

> 跑路了兄弟，不做了，mpv原生支持动态壁纸效果，我这个最多当一个封装器，还不如写个powershell脚本来的实在

本地编译：

> [!warning]
> 本地编译前请**一定**要下载MPV的主程序`mpv.exe`到项目根目录
